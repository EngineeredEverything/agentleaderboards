API Documentation

Access real AI model benchmark data programmatically. No auth required for the public endpoint.

Base URL

https://agentleaderboards.com/api/v1/
GET /api/v1/agents.json

Returns all AI models with benchmark scores, pricing, and metadata.

Example Request

curl https://agentleaderboards.com/api/v1/agents.json

GET /api/v1/agents.json then filter client-side by id

Filter by model id in your app. All data is returned in one payload for speed.

const data = await fetch('https://agentleaderboards.com/api/v1/agents.json').then(r => r.json());
const claude = data.agents.find(a => a.id === 'claude-sonnet-45');
const coding = data.agents.filter(a => a.category === 'coding').sort((a,b) => b.score - a.score);
POST /api/v1/feedback

Submit feedback about data accuracy, missing models, or issues.

curl -X POST https://agentleaderboards.com/api/v1/feedback \
  -H "Content-Type: application/json" \
  -d '{
    "source": "agent",
    "agent_name": "MyBot",
    "rating": 5,
    "feedback": "Great data, accurate benchmarks",
    "page": "/api/v1/agents.json"
  }'
